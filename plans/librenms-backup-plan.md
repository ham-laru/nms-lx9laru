# LibreNMS Backup Plan

## What is NOT backed up

### Managed by nix/git

- LibreNMS application files — in the nix store, rebuilt from `flake.nix`
- Custom UI blade (`custom.blade.php`) — tracked in `overlays/librenms/`
- SOPS-encrypted secrets (`librenms_api_token`) — encrypted in the git repo
- SNMP v3 settings — stored in the LibreNMS DB, covered by DB dump
- Oxidized service config — generated by NixOS from `services.oxidized.*` in the flake (verify this; if manually managed, add to backup)

### Excluded from backup (ephemeral/cache)

- `/var/lib/librenms/cache/` — runtime cache, rebuilt automatically
- `/var/lib/librenms/storage/framework/` — Laravel framework cache
- `/var/lib/librenms/storage/debugbar/` — debug profiler cache
- `/var/lib/librenms/version` — derivable from nix
- `/var/lib/librenms/package` — nix store pointer, not useful outside nix
- `/var/lib/librenms/one_minute_enabled` — runtime flag file

## What to back up

| Component | Location | Size | Priority | Notes |
|---|---|---|---|---|
| MariaDB database | `librenms` DB via socket | small | Critical | Devices, users, alerts, all DB-stored config |
| Main config | `/var/lib/librenms/.env` | tiny | Critical | APP_KEY, DB credentials — required for restore |
| JSON config | `/var/lib/librenms/config.json` | tiny | Critical | Runtime settings; may not exist if not configured |
| PHP config | `/var/lib/librenms/config.php` | tiny | Critical | PHP config overrides; may not exist |
| Storage | `/var/lib/librenms/storage/app/` | small | Useful | App data (user uploads, etc.) |
| Oxidized device configs | `/var/lib/oxidized/git-repos/default.git` | small | Critical | Git repo of all router/switch configs — most operationally valuable data on the machine |
| Oxidized SSH keys | `/var/lib/oxidized/.ssh/` | tiny | Critical | Private keys used to SSH into network devices |
| RRD files | `/var/lib/librenms/rrd/` | ~1.9 GB | Nice-to-have | Time-series graph data; losing them loses historical graphs only, LibreNMS continues working |

## Existing tooling

`packages/librenms-utils/librenms-backup-mysql.sh` does a basic `mysqldump | gzip`. The new automated backup supersedes it; that script should be removed once the new service is tested.

## Backup strategy

Two independent systemd services so the small critical backup runs fast and reliably regardless of the RRD sync:

### 1. Critical backup (daily): DB + config + Oxidized

- Dump DB via Unix socket (no password needed — `librenms` OS user authenticates via socket auth)
- Archive with config files and Oxidized data into a timestamped `.tar.gz`
- Verify archive integrity with `gzip -t` before pushing
- Push to NAS; rotate NAS archives older than 30 days
- Rotate local archives older than 7 days (local copy is a short buffer only)

### 2. RRD sync (daily, ~1.9 GB)

- `rsync -a` the RRD directory to a persistent path on NAS (no archiving)
- RRD files are written every 5 min so essentially all 1.9 GB transfers each run — acceptable on a local network
- No retention needed; NAS is an in-place mirror

## NAS connection (TBD)

Scripts use two env vars from an `EnvironmentFile`: `LIBRENMS_BACKUP_HOST` (e.g. `user@nas`) and `LIBRENMS_BACKUP_PATH` (e.g. `/backups/librenms`). Preferred method is rsync over SSH with a dedicated key restricted on the NAS with a forced `rsync`-only `authorized_keys` entry.

**Security note**: the archive contains `.env` (APP_KEY, DB credentials) and Oxidized SSH private keys to production network devices. Consider GPG-encrypting the archive before transfer if the NAS is shared or the transport is unencrypted.

## NixOS implementation

Two services using `pkgs.writeShellApplication` so scripts live in the nix store — version-controlled, tool dependencies explicit, `set -euo pipefail` implicit.

### Critical backup script

```nix
backupScript = pkgs.writeShellApplication {
  name = "librenms-backup";
  runtimeInputs = [ pkgs.mariadb pkgs.rsync ];
  text = ''
    BACKUP_DIR="/var/lib/librenms/backup"
    DATE=$(date +%Y%m%d)
    DB_DUMP="''${BACKUP_DIR}/librenms-''${DATE}.sql"
    ARCHIVE="''${BACKUP_DIR}/librenms-''${DATE}.tar.gz"
    HOST="''${LIBRENMS_BACKUP_HOST:-}"
    BACKUP_PATH="''${LIBRENMS_BACKUP_PATH:-}"

    # Remove temp SQL dump on any exit; remove partial archive if creation fails
    archive_ok=false
    cleanup() {
        rm -f "''${DB_DUMP}"
        if [[ "''${archive_ok}" != true ]]; then rm -f "''${ARCHIVE}"; fi
    }
    trap cleanup EXIT

    mysqldump \
        --socket=/run/mysqld/mysqld.sock \
        --single-transaction --skip-lock-tables \
        librenms > "''${DB_DUMP}"

    # --ignore-failed-read skips optional files (config.json, config.php) without aborting
    tar --ignore-failed-read -czf "''${ARCHIVE}" \
        "''${DB_DUMP}" \
        /var/lib/librenms/.env \
        /var/lib/librenms/config.json \
        /var/lib/librenms/config.php \
        /var/lib/librenms/storage/app/ \
        /var/lib/oxidized/git-repos/default.git \
        /var/lib/oxidized/.ssh/

    gzip -t "''${ARCHIVE}"
    archive_ok=true

    if [[ -n "''${HOST}" ]]; then
        rsync -a "''${ARCHIVE}" "''${HOST}:''${BACKUP_PATH}/archives/"
        # Rotate NAS archives (non-fatal if SSH fails — local copy still present)
        ssh "''${HOST}" "find ''${BACKUP_PATH}/archives -name 'librenms-*.tar.gz' -mtime +30 -delete" || true
    fi

    # Rotate local archives (keep 7 days; -mtime +6 deletes files older than 6 days)
    find "''${BACKUP_DIR}" -name "librenms-*.tar.gz" -mtime +6 -delete
  '';
};
```

### RRD sync script

```nix
rrdSyncScript = pkgs.writeShellApplication {
  name = "librenms-rrd-sync";
  runtimeInputs = [ pkgs.rsync ];
  text = ''
    HOST="''${LIBRENMS_BACKUP_HOST:-}"
    BACKUP_PATH="''${LIBRENMS_BACKUP_PATH:-}"
    if [[ -n "''${HOST}" ]]; then
        rsync -a --delete /var/lib/librenms/rrd/ "''${HOST}:''${BACKUP_PATH}/rrd/"
    fi
  '';
};
```

### Nix service + timer config

```nix
systemd.services.librenms-backup = {
  description = "LibreNMS critical backup";
  after = [ "mysql.service" "network.target" ];
  requires = [ "mysql.service" ];
  serviceConfig = {
    Type = "oneshot";
    ExecStart = lib.getExe backupScript;
    User = "librenms";
    StateDirectory = "librenms/backup";       # creates /var/lib/librenms/backup owned by librenms
    EnvironmentFile = "/etc/librenms-backup.env";  # LIBRENMS_BACKUP_HOST, LIBRENMS_BACKUP_PATH
  };
};

systemd.timers.librenms-backup = {
  wantedBy = [ "timers.target" ];
  timerConfig = {
    OnCalendar = "03:00";
    Persistent = true;
  };
};

systemd.services.librenms-rrd-sync = {
  description = "LibreNMS RRD mirror sync";
  after = [ "network.target" ];
  serviceConfig = {
    Type = "oneshot";
    ExecStart = lib.getExe rrdSyncScript;
    User = "librenms";
    EnvironmentFile = "/etc/librenms-backup.env";
  };
};

systemd.timers.librenms-rrd-sync = {
  wantedBy = [ "timers.target" ];
  timerConfig = {
    OnCalendar = "04:00";    # offset from critical backup to avoid I/O contention
    Persistent = true;
  };
};
```

## Restore procedure

`tar` strips the leading `/` when creating archives, so all paths inside are relative. Restore with `-C /` to land files in the correct locations.

1. **Restore `.env`** (contains APP_KEY — must come first):
   ```bash
   tar -xzf librenms-YYYYMMDD.tar.gz -C / var/lib/librenms/.env
   ```

2. **Restore and import database**:
   ```bash
   tar -xzf librenms-YYYYMMDD.tar.gz -C /
   mysql librenms < /var/lib/librenms/backup/librenms-YYYYMMDD.sql
   ```

3. **Restore Oxidized data** (fix SSH key permissions after extract):
   ```bash
   chmod 700 /var/lib/oxidized/.ssh
   chmod 600 /var/lib/oxidized/.ssh/*
   chown -R oxidized:oxidized /var/lib/oxidized/
   ```

4. **Restart services**:
   ```bash
   systemctl restart librenms oxidized
   ```
